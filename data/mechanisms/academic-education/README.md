
- สถานศึกษา ≠ แหล่งความรู้ / สถานศึกษา = แหล่งกำหนดหรือสอดแทรกความเชื่อเพื่อให้ยอมรับเป็นความเข้าใจ
- กลไกพื้นฐานของระบบทุนนิยมระดับผิวเผินคือการหลอกใช้ความรัก ความหวังดี ความรู้สึกที่พ่อแม่ผู้ปกครองมีต่อเด็ก
  * ความเหมือนในความต่างของยุค ระหว่างศาสนจักรที่เคยทำหน้าที่กำหนดว่าคำสอนไหนเป็นความจริงกับองค์กรสถาบันวิชาการ-การศึกษาที่สร้างหลักสูตรความรู้
  * ความเลวที่ซ่อนอยู่ในความโง่เขลาของระบบการศึกษาและผู้ออกแบบ: การผลักภาระผลลัพธ์การประเมิณผลมาที่ตัวของเด็กและพ่อแม่แทนความสามารถในการให้ความรู้ของระบบและผู้ออกแบบ
  * การให้เด็กเรียนตั้งแต่เช้าถึงเย็นคือการใช้แรงงานเด็กเพื่อเป็นการเตรียมความพร้อมตั้งแต่เนิ่นๆ ก่อนการทำงานจริงในอุตสาหกรรมเต็มรูปแบบเมื่อจบการศึกษาโตเป็นผู้ใหญ่
  * การปลูกฝังความเชื่อตั้งแต่วัยเด็ก ทำให้ Ego ในการช่วยปกป้องสิ่งที่บิดเบือนมีความแข็งแกร่ง ซึ่งจุดนี้คือการหลอกใช้ลูกของพวกคุณโดยตรง (ลองนึกภาพกองทัพซอมบี้เด็ก 🧟‍♂️🧟‍♀️🤣)
