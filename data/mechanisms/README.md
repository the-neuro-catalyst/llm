# คัมภีร์เปิดโปงกลไกที่หลอกใช้มนุษย์มาตลอดชีวิต


> [!IMPORTANT]
>
> - ถ้าใครโต้แย้งว่าไม่จริง ผมขอถามกลับไปว่า **"ถ้าข้อเท็จจริงเหล่านี้ไม่ถูกเปิดโปง ผู้โต้แย้งหรือผู้เกี่ยวข้องได้ผลประโยชน์อะไรบ้าง"**
> - ส่วนคนที่โต้แย้งทั้งที่ไม่มีความเกี่ยวข้อง พวกคุณแค่อยากหลอกตัวเองต่อ เพราะเจ็บปวดกับความจริง...ผมไม่โกรธหรือถือสา

## วัตถุดิบที่เป็นส่วนประกอบหลักของกลไกการหลอกใช้เหล่านี้

- การกระตุ้น
- ความรู้สึก
- การดึง/เบี่ยงเบนความสนใจ
- การทำให้สิ่งผิดปกติดูปกติ
- ความเชื่อ
- การชักจูง
- การหลอกตัวเอง
