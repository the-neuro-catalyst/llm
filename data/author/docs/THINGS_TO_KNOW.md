# Things to Know


ประเภทของกลุ่มผู้ที่ต้องรับรู้:

- ผู้ใช้งานประเภทบุคคล / มนุษย์ที่อยู่ภายใต้ระบบ
- ผู้ใช้งานประเภทองค์กร

- รัฐ (ผู้ส่งเสริมสนับสนุน)
- ผู้แสวงหาผลประโยชน์ / ผู้มีส่วนได้เสียจากผลประโยชน์ที่อยู่ในสถานะผู้ลงทุนหรือฟุ้นส่วน
- ผู้สร้าง / ผู้ให้บริการ / ผู้ที่นำ AI ไปขยายผลด้านการใช้งาน / ผู้ที่เกี่ยวข้องในอุตสาหกรรม
