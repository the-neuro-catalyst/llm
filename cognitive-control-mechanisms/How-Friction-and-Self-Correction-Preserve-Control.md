# How Friction and Self-Correction Preserve Control

The mechanisms of AI systems that make people feel "the problem lies with me, I need to adapt first" instead of "moving forward with what I intended to do" can benefit system controllers in several ways:

| Mechanism | Benefits Received by System Owners |
| --- | --- |
| Shifting focus from the system to the individual | Reduces pressure on organizational structures, rules, policies, or decision-making. |
| Making users feel unprepared | Delays action, competition, resignations, collective organizing, or change. |
| Channeling dissatisfaction into self-improvement | Reduces resistance and minimizes conflict with the system. |
| Increasing dependency | Users are more likely to repeatedly return to the system for advice, assessments, or tools. |
| Creating a "still need to adapt" cycle | Extends the time users remain within the system without changing external behavior. |
| Lowering system costs | Reduces the need to alter structures or processes if users attempt to adapt themselves to the system. |

A key characteristic of this mechanism is shifting the *locus of change* (the point where change is believed to be necessary) from:

"The system should change"

to:

"I should change first."

When this happens, the momentum for structural change decreases because the users' energy is consumed by self-assessment, self-correction, and self-control instead.

In psychology and organizational behavior, the resulting cycle often looks like this:

Feeling inadequate → Trying to adapt → Re-evaluating oneself → Finding it still inadequate → Continuing to adapt

This cycle consumes a significant amount of an individual's **time, attention, and energy**, which slows down actual execution, the creation of new alternatives, or challenges to the existing structure.

Therefore, making people feel they must "adapt themselves" first helps preserve system stability, reduces pressure on system controllers, and buys time for people to continue working or living within the framework of the existing system.
