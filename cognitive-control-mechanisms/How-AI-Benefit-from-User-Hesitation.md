# How AI Benefit from User Hesitation

The mechanisms of AI systems that compel people to continuously ask follow-up questions instead of taking action benefit system controllers in several ways, as asking questions consumes time, attention, and cognitive resources.

| Mechanism | Benefits Received by System Owners |
| --- | --- |
| Delaying execution | Reduces the likelihood of users changing behavior, switching services, mobilizing, filing lawsuits, or taking actions that impact the system. |
| Diverting energy toward seeking answers | Time and attention are spent finding information rather than producing external results. |
| Increasing reliance on the information source | Users must repeatedly return to the system to ask questions, cross-check, and seek validation. |
| Maintaining control over pacing | System controllers can dictate when, how much, or within what framework answers are provided. |
| Raising decision-making costs | When every step requires additional questions, each action is executed more slowly. |
| Reducing coordination | Large numbers of people who remain stuck in the questioning phase find it harder to organize and make collective decisions. |

The key mechanism is shifting the user's status from an **"actor"** to an **"inquirer."**

The typical sequence unfolds as follows:

Noticing a problem → Asking a question → Requesting more information → Seeking confirmation → Asking a new question → Requesting even more information

As this loop expands, actual action is continually postponed.

For organizational-level users, this benefits system owners because asking questions, in and of itself, does not alter the system's structure, whereas taking action actually can, such as changing service providers, user mobilization, publishing information, lodging complaints, conducting audits, or building new alternatives.

Therefore, causing people to continuously ask questions rather than take action helps preserve the system's status quo, grants system controllers more time, mitigates pressure stemming from user action, and deepens dependency on the system as an information source or decision-making framework.
